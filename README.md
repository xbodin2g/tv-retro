# 📺 TV Rétro - Grilles des années 80/90

Une application web rétro pour revivre les grilles TV des années 80 et 90 et créer des playlists via TuneMyMusic.

## 🎯 Fonctionnalités

- ✅ Parcourir les grilles TV par date ou par chaîne
- ✅ Créer et gérer votre playlist personnelle
- ✅ Exporter vers TuneMyMusic
- ✅ Interface rétro années 80/90 (effet CRT, néons, pixel art)
- ✅ Compatible Android, iOS, PC (PWA)
- ✅ Mode hors ligne (Service Worker)

## 🚀 Déploiement sur GitHub Pages

### Étape 1 : Créer un dépôt GitHub

1. Allez sur [GitHub](https://github.com)
2. Créez un nouveau dépôt (ex: `tv-retro`)
3. **Important** : Cochez "Add a README file"

### Étape 2 : Uploader les fichiers

1. Clonez votre dépôt localement ou utilisez l'interface web GitHub
2. Copiez tous les fichiers suivants :
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
   - `service-worker.js`

### Étape 3 : Ajouter des icônes (optionnel mais recommandé)

Créez ou téléchargez deux icônes :
- `icon-192.png` (192x192 pixels)
- `icon-512.png` (512x512 pixels)

Vous pouvez utiliser des générateurs d'icônes gratuits comme :
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- [Favicon.io](https://favicon.io/)

### Étape 4 : Activer GitHub Pages

1. Allez dans **Settings** de votre dépôt
2. Section **Pages**
3. Source : **Deploy from a branch**
4. Branch : **main** (ou master)
5. Dossier : **/ (root)**
6. Cliquez sur **Save**
