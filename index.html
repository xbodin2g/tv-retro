À propos de TV Rétro

📺 Objectif : Reconstituer des journées TV des années 80 et 90

🎬 Sources : Depot101 & Archives80

🎵 Intégration : Compatible avec TuneMyMusic

📱 Compatible : Android, iOS, PC

📖 Comment utiliser ?

  1. Allez dans Parcourir
  2. Choisissez une date ou une chaîne
  3. Sélectionnez les programmes qui vous intéressent
  4. Cliquez sur + Playlist pour les ajouter
  5. Dans Ma Playlist, exportez vers TuneMyMusic

💻 Technologies

Cette application est une PWA (Progressive Web App) qui fonctionne sur tous les appareils.
