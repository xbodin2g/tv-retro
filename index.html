À propos de TV Rétro

📺 Objectif : reconstituer partiellement des journées TV des années 80 et 90.

🎬 Sources : Depot101 et Archives80, fusionnées sans doublons.

🗞️ Présentation : grille chaîne par chaîne, dans l’esprit d’un magazine TV.

🧩 Extraits : les blocs jeunesse peuvent être détaillés programme par programme.

🎵 Export : liste de programmes à utiliser avec TuneMyMusic.

📱 Compatible : Android, iOS, PC via une Progressive Web App.

📖 Comment utiliser ?

  1. Ouvrez l’onglet Parcourir.
  2. Choisissez une année.
  3. Sélectionnez une journée disponible.
  4. Consultez la frise et la grille chaîne par chaîne.
  5. Dépliez les blocs jeunesse pour voir les extraits.
  6. Ajoutez programmes ou extraits à la playlist.
  7. Dans Ma Playlist, utilisez le bouton Retour à la journée si besoin.
  8. Choisissez le format d’export, puis copiez la liste dans TuneMyMusic.

💻 Technologies

Cette application est une PWA statique hébergée sur GitHub Pages.

Les données sont générées par des scripts Python exécutés avec GitHub Actions.

Les playlists sont sauvegardées localement dans votre navigateur.
